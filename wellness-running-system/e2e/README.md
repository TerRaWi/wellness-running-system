# ชุดทดสอบ Playwright (e2e)

เปิดเบราว์เซอร์แล้วคลิกใช้งานหน้าแอดมินและหน้าพนักงานแทนคน ใช้**ฐานข้อมูลทดสอบบนเครื่องนี้เท่านั้น**
(ข้อมูลสมมติ ไม่แตะ Aiven / ข้อมูลพนักงานจริง — `db/seed.js` ไม่ยอมทำงานกับ host อื่นนอกจาก localhost)

| คำสั่ง | ทำอะไร |
| --- | --- |
| `npm test` | ทดสอบการทำงาน 21 รายการ (แอดมิน 15, พนักงาน 6) |
| `npm run test:visual:update` | ถ่ายภาพหน้าจอ 35 ภาพเก็บเป็นต้นแบบ |
| `npm run test:visual` | ถ่ายใหม่แล้วเทียบกับต้นแบบทีละพิกเซล |
| `npm run report` | เปิดรายงานผลล่าสุด (มีภาพ/trace ของเทสต์ที่ไม่ผ่าน) |

## ติดตั้งครั้งแรก

```bash
cd e2e
npm install
npx playwright install chromium
```

## รันทุกครั้ง

1. เปิด MySQL ทดสอบค้างไว้ในอีกหน้าต่าง (port 3320 แยกจาก MySQL ปกติของเครื่อง ครั้งแรกจะสร้างให้เอง):
   ```bash
   npm run db:start
   ```
2. อีกหน้าต่าง: `npm test`

ชุดทดสอบเปิด API (port 4100) และหน้าเว็บ (`vite --mode e2e`, port 5188) ให้เอง ไม่ใช้ `server/.env`
ทุกไฟล์ทดสอบล้างฐานข้อมูลแล้วใส่ข้อมูลตัวอย่างใหม่ก่อนเริ่ม (schema มาจาก `Docs/EER Diagram/wellness.sql`
— ถ้าแก้ schema ให้รัน `npm run db:recreate`)

## ตรวจว่าแก้โค้ดแล้วหน้าตาไม่เปลี่ยน

ภาพต้นแบบขึ้นกับเครื่อง/ฟอนต์/วันที่ จึงไม่ได้เก็บใน git — สร้างใหม่ก่อนแก้ทุกครั้ง:

1. ก่อนแก้โค้ด: `npm run test:visual:update`
2. แก้โค้ด
3. `npm run test:visual` → ถ้าภาพไหนต่าง ดูภาพเทียบได้ใน `npm run report`

ตั้งใจเปลี่ยนหน้าตาเมื่อไหร่ ให้รันข้อ 1 ใหม่หลังแก้เสร็จ

## หมายเหตุ

- ฝั่งพนักงานล็อกอินผ่าน LINE จริงไม่ได้ — โหมด e2e สลับ `@line/liff` เป็นตัวจำลอง (`client/e2e-mocks/liff.js`)
  และเทสต์ตอบคำขอ `/api/auth/line-login` แทนเซิร์ฟเวอร์ด้วย token ที่เซ็นด้วย secret ของชุดทดสอบ
- อัปโหลดรูป (Cloudinary) ไม่ได้ทดสอบ
- หน้าแอดมินซ่อนแท็บที่ไม่ได้เปิดด้วย `hidden` (ยังอยู่ใน DOM) เทสต์จึงค้นหาเฉพาะองค์ประกอบที่มองเห็น
